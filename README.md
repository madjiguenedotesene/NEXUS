# 🚀 NEXUS - Écosystème de Candidature Intelligente

NEXUS est une plateforme moderne conçue pour propulser les carrières professionnelles grâce à l'ingénierie de données et l'automatisation. Ce projet combine un générateur de CV Anti-ATS et un système de déploiement massif de candidatures.

## 🛠️ Architecture du Projet

Le projet est divisé en deux parties principales :
- **Frontend** : Développé avec React + Vite (Localisé dans `src/`).
- **Backend** : Serveur Node.js dédié à l'envoi d'emails sécurisés (Localisé dans `server/`).
